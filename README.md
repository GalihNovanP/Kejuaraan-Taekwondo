# ArenaTKD — Website Kejuaraan Taekwondo Indonesia

Website informasi kejuaraan taekwondo Indonesia: kalender kejuaraan, detail event, panduan nomor pertandingan (Kyorugi & Poomsae), kelas berat, ranking klub, dan hasil kejuaraan terbaru.

Website ini adalah konsep tampilan yang lebih rapi dan terstruktur, terinspirasi dari platform SIMPBTI (simpbti.id). Pendaftaran, bagan pertandingan, dan verifikasi piagam tetap dikelola melalui SIMPBTI.

## Cara menjalankan

Cukup buka file `index.html` di browser, atau kunjungi versi live melalui GitHub Pages.
